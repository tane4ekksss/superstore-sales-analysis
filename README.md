Анализ продаж суперстора (Superstore Sales Analysis)

Описание проекта 
Учебный проект по анализу данных о продажах розничной сети. 
Включает SQL-анализ, визуализацию в Python (Pandas, Matplotlib) и интерактивный дашборд в Power BI.

Стек 
SQL (SQLite) — агрегация, группировки, оконные функции, CTE, JOIN. 
Python (Pandas, Matplotlib) — визуализация, анализ. 
Power BI — интерактивный дашборд.

Структура репозитория 
analysis.ipynb — ноутбук с SQL-запросами и визуализацией, 
clean_data.csv — обработанные данные, 
superstore_dashboard.pbix — дашборд Power BI, 
images/ — графики и dashboard_preview.png — скриншот дашборда.

Ключевые выводы
География: Лидеры — West и East регионы. Крупнейшие города: New York City, Los Angeles, Seattle.
Товары: Самая прибыльная категория — Technology (145K), подкатегория — Copiers (55K). Убыточные: Tables (-17.7K).
Клиенты: Сегмент Consumer приносит больше всего продаж (~1.16M).
Скидки: Скидка не главный фактор убыточности. Binders с 37% скидкой прибыльна, а Bookcases с 21% убыточна.
Данные: Пропусков и дубликатов нет, данные чистые.
